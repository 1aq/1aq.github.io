Frequently asked questions

Why does a UAC prompt appear when I scan a physical disk?

Reading the raw sectors of a physical disk (\\.\PhysicalDriveN) requires an administrator token. Windows does not grant this to standard-user processes, including MSIX-packaged apps. The main DataRescue app stays unelevated; it only starts a separate, read-only helper process with elevation when you begin a physical-disk scan. If you decline the prompt, the app continues in disk-image mode.

Does DataRescue write to the disk it is scanning?

No. The recovery engine opens disks read-only. Recovered files are saved only to a location you choose.

Can I scan a disk image instead of a physical disk?

Yes. Disk-image files can be scanned without elevation, so no UAC prompt is required for that path.

Which file systems are supported?

FAT, exFAT, NTFS and Ext4, plus file carving for common file types when file-system metadata is unavailable.

Is my data uploaded anywhere?

No. All scanning and recovery happens locally on your computer. File contents are never transmitted.

The app reported a scan failure — what should I do?

Try scanning a disk image to confirm the app works, then re-run the physical-disk scan and accept the UAC prompt. If the problem persists, email the log location shown in the error dialog together with the Product ID.
